# Science AI Bot

A Python-based Science AI Bot that uses a science dataset,
Pandas, Tkinter, and the Google Gemini API to answer
science-related questions.

## Technologies Used

- Python
- Pandas
- Tkinter
- Google Gemini API
- CSV Dataset

## Features

- User can enter a science question
- Uses a science dataset
- Provides AI-generated answers
- Simple graphical user interface

## Project Files

- `science.py` — Main Python program
- `science_instruction_response_10000.csv` — Science dataset
